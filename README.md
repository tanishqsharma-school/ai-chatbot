 Class 10 AI Project: School Assistant Chatbot

This is a Python-based Chatbot designed for the curriculum. It demonstrates the fundamentals of **Natural Language Processing (NLP)**.

 Features
- **Text Normalization:** Automatically converts inputs to lowercase to avoid errors.
- **Intent Matching:** Scans sentences for key tokens and phrases.
- **Fallback Mechanism:** Handles unknown queries gracefully without crashing.
- **School Information:** Provides quick data regarding school hours, exams, and the AI syllabus.

 NLP Concepts Applied
1. **Tokenization & Keyword Extraction:** The program breaks down user sentences to find matching tokens like `exam`, `syllabus`, or `timing`.
2. **Text Standardization:** Uses `.lower()` to ensure user input variation does not break the logic.

 How to Run
1. Run the script using Python:
   ```bash
   python chatbot.py
   ```
